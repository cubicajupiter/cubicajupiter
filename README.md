## &nbsp;&nbsp;[miniRT](https://github.com/mordori/miniRT)

&nbsp;&nbsp;&nbsp;**C-based 3D Ray Tracing Engine**
- Two person teamwork building a 3D ray tracing engine from scratch
- C for low level vector maths, transformations & intersection algorithms
- Developed a shader based on the Phong reflection model
- Profiling of software and optimisation for real-time high performance
- Multithreading for increased performance

## &nbsp;&nbsp;[FdF](https://github.com/mordori/FdF)

&nbsp;&nbsp;&nbsp;**Simple wireframe model software renderer.**
- Implements a software-based geometry pipeline (Model->World->Clip->NDC->Screen)
- Uses the Liang-Barsky algorithm for line clipping and Bresenham’s algorithm for rasterizing the lines
- Includes an orbiting camera controller that emulates the navigation style of 3D modeling software like Blender
